# Travli — Global Local Travel Platform 🌍✨

> **"Travel Like a Local. Real People | Real Places | Real Experiences."**

Travli connects **Travelers, Locals, Guides, Chauffeurs, and Cultural Creators** into a unified ecosystem powered by a spatial 3D radar and dynamic local-matching engine.

---

## 🚀 Key Features

### 1. Pan-India Spatial 3D Heritage Radar & 29 States Integration
- **Interactive 3D Perspective Map**: Real-time corridors linking ancient monuments across India (Hyderabad, Varanasi, Jaipur, Hampi, Kochi, Amritsar, and all 29 states).
- **All 29 Indian States Repository**: Structured directory of must-visit sites, sacred temples, excavated archaeological monuments, regional cuisines, and verified chauffeurs.
- **Dedicated Driver Network**: High-altitude 4x4 mountain drivers, backwater coastal pilots, and executive airport transfer chauffeurs.

### 2. Algorithmic Local Matching Engine
- Filter verified native hosts by:
  - Language fluency (Telugu, Hindi, English, Urdu, Tamil, Kannada, Sanskrit, etc.)
  - Hourly budget sliders
  - Vehicle / AC transport requirements
  - Group party sizes and domain skills

### 3. Travli AI Companion & "No Fixed Plan" Mode
- AI assistant answering destination queries, layover recommendations, and wet-weather contingencies.
- **"No Fixed Plan" (NOW, NEXT, NEARBY)**: Dynamic recommendation engine adapting in real time to the traveler's selected destination.

### 4. Safety Center & Real-Time Marketplace
- 1-Tap SOS emergency broadcast system and helpline routing.
- **Travli Now**: Radar for immediate on-demand meetups with nearby verified hosts.
- Multi-role support: Traveler, Local Guide/Host, Chauffeur, and Admin Liquidity console.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Shadcn/UI patterns, Spatial 3D perspective grids
- **State & Data**: TanStack Query, React Context
- **Icons & Animation**: Lucide React, Framer Motion
- **Backend Schema**: Supabase PostgreSQL (`supabase/migrations/001_travli_core_schema.sql`)
